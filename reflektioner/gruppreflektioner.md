# Gruppreflektioner

Svara på var och en av frågorna nedan som grupp. MINST 100 tecken per fråga.

## Frågor

### Inledning

#### Sammanfatta projektets syfte, samt era gemensamma mål

För att förstå det agila arbetssättet och att samarbeta – Git Flow, Kanban, Scrum. Målet var att få ihop en fungerande webbapplikation i så stor utsträckning som möjligt.

#### Hur upplevde teamet projektet initialt?

Intressant att se hur vi arbetar tillsammans. En gruppmedlem hade jobbat såhär i de tidigare grupp-projekten medan en annan gruppmedlem aldrig hade jobbat på det här sättet. Vissa kände att det var lite läskigt att använda GitHub på riktigt och att få konflikter.

### Planering och genomförande

#### Beskriv hur ni inom teamet planerade projektet initialt

Vi gick igenom user stories och kompletterade Figma-skissen utifrån det. Därefter röstade vi fram value points och rangordnade user stories utefter dem.

#### Vilka steg har teamet tagit för att utveckla applikationen?

Figma-skiss, user stories. Vi hade en gruppdiskussion om hur vi ville att applikationen skulle se ut. De sidor vi har lagt till är bland annat loading page, menykategorisidan och om oss-sidan.

### Teamets utmaningar och lösningar

#### Vika var de största utmaningarna för teamet?

Vissa tyckte att det var svårt att använda git eftersom det blev konflikter. En gruppmedlem tyckte funktionaliteten för kategorierna på menysidan.

#### Hur löste eller hanterade teamet dessa utmaningar?

Vi löste utmaningarna som en grupp genom att vi kommunicerade med varandra, både via textchatt och videosamtal.

#### Vilka kompromisser inom teamet har ni gjort under projektets gång?

Vi har prioriterat att skapa det vi kan, vilket har resulterat i att viss funktionalitet har begränsats. Vi har skapat olika designversioner i Figma och sedan gemensamt kommit fram till vilken vi skulle använda.

### Teamets reflektion och utvärdering

#### Vad lärde sig gruppen inom projektet?

Vi känner oss säkrare på Git Flow, GitHub Projects (skapa user stories), skapa brancher. Vi har lärt oss att tänka annorlunda än när man jobbar individuellt

#### Hur kan gruppen förbättra sitt samarbete framöver?

Vi tycker att samarbetet har fungerat väldigt bra. Vi höll god kommunikation under hela projektet och så fort någon behövde hjälp så berättade det för de övriga gruppmedlemmarna. På Daily Scrums så var det sällan någon behövde hjälp, eftersom problemen löstes dagen innan.
